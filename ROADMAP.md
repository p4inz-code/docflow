# Docflow Roadmap

> **Last updated:** July 2026

## v1.0.0 — Release Candidate (Current)

The current release focuses on:
- ✅ Complete PDF viewing and annotation
- ✅ Multi-document workspace
- ✅ Professional editing tools
- ✅ Undo/redo with command pipeline
- ✅ Export to PDF, PNG, JPEG
- ✅ Keyboard-first UX

## v1.0.0 — Stable Release

### Quality
- [ ] Full ARIA accessibility on all components
- [ ] Per-subsystem ErrorBoundary boundaries
- [ ] GlobalErrorManager integration into all subsystems
- [ ] Unit tests for core subsystems
- [ ] Focus management (trap + restoration) for dialogs

### Polish
- [ ] Design tokens and CSS variables for theming
- [ ] Loading skeletons
- [ ] Micro-animations for interactions
- [ ] Improved empty states
- [ ] Middle-mouse-button pan

## v1.1.0 — Desktop Release

- [ ] Electron shell integration
- [ ] Native file system access
- [ ] System menu bar integration
- [ ] Native drag-and-drop from OS
- [ ] Auto-updater
- [ ] Windows/macOS/Linux installers

## v1.2.0 — Collaboration & Advanced Features
