# Support

## Getting Help

### Documentation
Start with the [documentation](docs/) for guides, architecture overviews, and release notes.

### GitHub Issues
For bug reports and feature requests, please open a [GitHub Issue](https://github.com/your-org/docflow/issues/new/choose).

### Community
- **Questions**: Use GitHub Discussions (coming soon)
- **Security vulnerabilities**: See [SECURITY.md](SECURITY.md)

### Before Opening an Issue
1. Search existing [issues](https://github.com/your-org/docflow/issues) for duplicates
2. Check the [known limitations](docs/KNOWN_LIMITATIONS.md)
3. Review the [FAQ](README.md#faq) if available

We aim to respond to all issues within 48 hours.
